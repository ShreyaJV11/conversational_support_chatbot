# File Types - Quick Summary

✓ .txt   - Plain text
✓ .md    - Markdown
✓ .json  - JSON data
✓ .yaml  - YAML config
✓ .yml   - YAML config
```

### 📄 Documents (3 types)

```

### 📊 Spreadsheets (3 types)
```
✓ .xlsx  - Excel (modern)
✓ .xls   - Excel (legacy)
✓ .csv   - CSV data
```

### 🌐 Web Files (2 types)
```
✓ .html  - HTML pages (with images ✨)
✓ .htm   - HTML pages (with images ✨)
```

### 🖼️ Images (3 types)
```
✓ .png   - PNG images (with OCR ✨)
✓ .jpg   - JPEG images (with OCR ✨)
✓ .jpeg  - JPEG images (with OCR ✨)
```

## 🎯 Image Support Summary

**Files that support images:**
- HTML/HTM - Extracts `<img>` tags ✅
- PDF - May extract embedded images ✅
- PPTX - May extract embedded images ✅
- PNG/JPG/JPEG - Direct image upload with OCR ✅

**Files without image support:**
- TXT, MD, JSON, YAML, YML
- DOCX
- XLSX, XLS, CSV

## 📏 Limits

- **Max file size:** 5 MB
- **Max files:** Unlimited
- **Processing time:** Varies by format
