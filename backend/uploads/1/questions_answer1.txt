Here is the option to install/download the Chrome HighWire Extension
Option #1:

1. Make sure you are logged in using your @highwirepress.com google account. The extension is only available to those who have a highwirepress.com google account.

2. Go to: https://chrome.google.com/webstore/detail/highwire/aonplpejmipgeacjdappkbjdkckhgoof and install the extension. 

If you get a message such as "The requested URL was not found on this server. That's all we know.", you are most likely not logged into the chromestore with your highwirepress.com account.
Go to https://chrome.google.com/webstore/category/extensions
Make sure in the upper right corner it it has your highwirepress.com account.  If not, click the down arrow and select your highwirepress.com account OR "sign in with another account" and sign in with your Highwirepress.com account
Once signed in as highwirepress.com, click https://chrome.google.com/webstore/detail/highwire/aonplpejmipgeacjdappkbjdkckhgoof again to install the extension.  

Option #2:

You may also install this extension manually at chrome://extensions/ with this file highwire-chrome-extension-v2.crx.  You will need to enable Developer mode.



Option #3:

Last option to install is by downloading the zip file directly from github and installing in Chrome manually

download https://github.com/highwire/highwire-chrome-extension
In chrome go to chrome://extensions and activate the Developer Mode toggle on the upper right
Click 'Load unpacked' and navigate to the highwire-chrome-extension folder you saved in step 1

what is the process for Internal Escalation Matrix in highwire 

1. Purpose
This document outlines the internal escalation workflow for Salesforce-related issues requiring support, SYSOPS, engineering, and leadership involvement. It ensures timely resolution, clear ownership, and transparent communication across teams.

2. Scope
This escalation matrix applies to:

Salesforce case escalations

Support team operations

SYSOPS and Engineering collaboration

Platform leadership involvement for high-priority or cross-team issues

3. Escalation Flow Summary


Support Team
    ↓
Engineering Team (Support) (with SYSOPS/Engineering if needed)
    ↓
Support Lead (with SYSOPS / Engineering Lead if needed)
    ↓
Director, Platforms (with EMs/PMs if needed)
    ↓
VP, Platform
   ↓
SVP, Platform



4. Roles & Responsibilities
Support Team
Logs issues and assigns priority

Provides initial triage and documentation

Routes cases to Support team

Engineering Team (Support)
Primary owner of incoming escalations

Performs investigation and resolution attempts

Collaborates with SYSOPS/Engineering for technical assistance

Support Lead
Provides guidance on complex cases

Drives cross-team coordination

Decides when to escalate to Platform leadership

SYSOPS / Engineering Teams
Offer technical analysis and fixes

Engage EMs/PMs for roadmap-level or systemic issues

Director, Platforms
Reviews escalated cases requiring leadership oversight

Allocates engineering resources as needed

Advises on technical, operational, or product-level implications

VP, Platform
Handles high-impact or cross-functional escalations

Communicates risk or delays to executive stakeholders

SVP, Platform
Final point of escalation

Engages organizational leadership for major service disruptions or strategic decisions

5. Detailed Escalation Matrix


Level 1	Support Team	—	Case creation; issue identified	Salesforce Case Queue
Level 2	Engineering Team (Support)	SYSOPS / Engineering	Technical investigation required	JIRA
Level 3	Support Lead	SYSOPS / Engineering Lead	Issue unresolved within SLA; requires leadership judgement	JIRA
Level 4	Director, Platforms	EMs / PMs	Cross-team coordination needed; potential product impact, Unsatisfactory RCA, and High recurrence of the issue	JIRA
Level 5	VP, Platform	Director / Support Lead	High-impact issue; customer or production risk	JIRA / Direct escalation channel
Level 6	SVP, Platform	VP / Director	Strategic or business-critical impact	JIRA / Executive communication channels
6. Escalation Guidelines
Always include case ID, impact description, and steps taken so far before escalating.

Ensure Slack escalation channels are used for urgent issues.

Escalation should follow the sequence unless severity necessitates skipping levels.

Document decisions in the appropriate system (Jira, Salesforce case notes, or internal logs).

7. Communication Expectations
Each escalation point must acknowledge receipt within the defined response time.

Updates must be posted until the issue is resolved or ownership is transferred.

Leadership must be informed immediately of issues impacting customers, revenue, or SLAs.

HW Intelligent Commerce Configuration Task List
Ans
To setup HW Intelligent Commerce, there are a number of items that need to be addressed.

1. Foxycart Setup
This is done by a Site Developer on the Professional Services Team.

To schedule this work, the Project Manager should create a Project Specific JIRA issue to schedule this work.

Foxycart Stores need to be setup: HW Intelligent Commerce Foxycart configuration 

FoxyCart Store Setup

The Site Developer will setup the Beta (development), QA and Production stores.

 
2. Access Control Configuration
This is done by a Site Developer on the Professional Services Team.

To schedule this work, the Project Manager should create a Salesforce Ticket to schedule this work.

For a new site, Access Control needs to be setup: https://sites.google.com/a/highwire.org/access-control/how-to/create-a-new-ac-webapp

By default, Intelligent Commerce is not enabled on Access Control and needs to be setup: https://sites.google.com/a/highwire.org/access-control/configure-ac-webapp-for-ecom2

The Engineer will setup Development, QA and Production webapps.

Install eCommerce Suite (migrated)



3. Intelligent Commerce Catalog Setup
This is done by a Site Developer on the Professional Services Team.

To schedule this work, the Project Manager should create a PLATTRIAGE JIRA issue to schedule this work. If a detailed price list is required, the Pricing Catalog Spreadsheet must be completed and attached to the JIRA issue, e.g. sample Springer Pricing Catalog

Intelligent Commerce Catalog needs to be setup: Intelligent Commerce Catalog Setup

The Intelligent Commerce Platform Engineer will setup the Development, QA and Production catalogs, using equivalent Foxycart Stores and Access Control webapps.

4. Drupal Site Development
This is done by a Site Developer on the Professional Services Team.

To schedule this work, the Project Manager should create a JIRA issue to schedule this work.

Drupal sites need to be setup: FoxyCart Integration & Configuration (Drupal)

Visual clues and easily identifiable icons to help site navigation
Article navigation that travels with scrolling
Increased space for placement of standardized advertisements

stopsite [options] -a

options:

-h this help blurb

-d stop the dev server (default is prod)

-a stops all sites on all machines

-m stops all sites on the specified machine(s)

-e use a perl regular expression to specify journal sites

-v verbose mode, spits out more info

-f force restart

-lsof use lsof to scan for processes still bound to ports

-apache only work on the HTTPD process

-jserv only work on the jserv processes

-seq restart only the jserv for the given number (e.g., 1, 2-3)

-nojit disable the Just In Time compiler

-altvm execute the alternate JVM

--debug execute JNDI debugger on the specified port

--profile execute OptimizeIt Profiler on the specified port

--tdebug execute OptimizeIt Thread Debugger on the specified port

-null-logs clear the jserv logs before restarting
